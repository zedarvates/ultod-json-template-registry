# Créatures originales — recettes de revue

Ces instantanés proviennent des ateliers de l’éditeur de créatures. Les recettes sont des documents de revue versionnés ; leurs générateurs et modèles source ne sont pas inclus. Elles ne constituent pas des entrées strict-v1 ni des génomes Xeno natifs. La capture de chaque fiche montre la variante reconstruite à partir de la recette exportée. Les modèles ne sont pas qualifiés pour une intégration en jeu sur cette seule base.
