# Comparaison de six bases de revue existantes

Ces GLB sont des instantanés de modèles déjà présents dans le bestiaire de l'éditeur, et non des créations nouvelles de cette PR. Leurs métadonnées locales les présentent comme des travaux originaux de revue ; les paramètres et les limites sont résumés dans `manifest.json`. Chaque copie a le même SHA-256 que le modèle chargé pour la capture et que son manifeste source lorsqu'il est renseigné.

Les captures montrent le chargement dans l'éditeur de créatures, matériaux source, sans jouer les animations et avec l'IK désactivée. Plusieurs niveaux de détail peuvent être affichés simultanément dans ce chemin d'import. Le contrôle ne prouve pas la locomotion, la qualité des textures, les raccords ou la conformité aux références.

- Cheval : silhouette plus lisible, mais ce cheval de selle ne reproduit pas le cheval de trait massif de la référence.
- Crabe : corps, huit pattes et pinces visibles ; proportions et aspect réaliste restent à améliorer.
- Bovin : la source est une **vache** brune, pas le taureau de la référence ; comparaison seulement.
- Serpent : spécimen allongé, pas la pose enroulée de la référence.
- Rat et mouton : silhouettes plus lisibles ; fidélité des détails et rendu final restent à revoir.

La gelée a aussi été inspectée mais n'est pas redistribuée dans ce lot : sa provenance n'a pas été suffisamment établie ici. Aucune base équivalente de lama n'a été identifiée. Ces six fichiers restent `review_only` et ne terminent pas les huit exercices.
