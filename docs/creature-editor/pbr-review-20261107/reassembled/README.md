# Réassemblages statiques PBR — revue expérimentale

Les six modèles cheval, mouton, lama, rat, crabe et gelée sont assemblés depuis des GLB de pièces existants ; le taureau et le serpent restent issus des modèles animés antérieurs. Le cheval n'a toujours pas de véritable tête. Ces six reconstructions ne sont pas riggées. Les huit fichiers sont des copies de revue, non des modèles finalisés.

Chaque fichier a été importé dans l'éditeur avec l'IK désactivée, puis photographié en mode matériaux source. Les rendus restent insuffisants : géométries très simplifiées, jambes disjointes, textures répétitives et absence de normale de relief. Les couleurs de sommets sont présentes dans les GLB qui en avaient sur les pièces inspectées, mais leur fidélité visuelle et la préservation de toutes les régions ne sont pas validées.

La carapace et les pinces du crabe ainsi que la tête du rat, manquantes dans les candidats riggés précédents, sont présentes dans ces reconstructions statiques. Les UV ont été calculés automatiquement ; leurs coutures et densités n'ont pas été validées. `manifest.json` identifie les fichiers sources et leurs empreintes. `browser_results.json` documente l'import, sans constituer une validation artistique ou de l'animation.
