# Abilities templates

## Purpose

Minimal declarative abilities identity and classification.

## Required fields

`display_name`. Optional kind and category tags are defined by the exact schema.

## Authoritative exclusions

Excluded: stats, damage, healing, costs, cooldowns, range, progression, requirements, rewards, recipes, markets, effects, lore, dialogue, and asset paths.

## Intended consumers

LLM pipeline only. Zig support requires separate typed-adapter evidence.

## Compatibility evidence

None verified.

## Versioning

Templates and family schemas follow independent SemVer.
