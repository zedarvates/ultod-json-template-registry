# Dungeons templates

## Purpose

Minimal declarative dungeons identity and classification.

## Fields

`display_name`; optional `theme_tag`.

## Authoritative exclusions

Excluded: layouts, coordinates, physics, timings, rewards, probabilities, spawns, runtime metrics, lore, dialogue, and asset paths.

## Intended consumers

LLM pipeline only. Zig support requires separate typed-adapter evidence.

## Compatibility evidence

None verified.

## Versioning

Templates and family schemas follow independent SemVer.
