# Events templates

## Purpose

Minimal declarative events identity and classification.

## Required fields

`display_name`. Optional classification tags are defined by the exact schema.

## Authoritative exclusions

Excluded: stats, phases, loot, anatomy, assets, objectives, rewards, schedules, waves, coordinates, palettes, probabilities, requirements, lore, and runtime mechanics.

## Intended consumers

LLM pipeline only. Zig support requires separate typed-adapter evidence.

## Compatibility evidence

None verified.

## Versioning

Templates and family schemas follow independent SemVer.
