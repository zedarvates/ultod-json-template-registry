# Recipes templates

## Purpose

Minimal declarative recipes identity and classification.

## Required fields

`display_name`; optional profession, station, or category tags.

## Authoritative exclusions

Excluded: ingredients, quantities, skill thresholds, timings, probabilities, costs, rewards, loot tables, experience, and runtime rules.

## Intended consumers

LLM pipeline only. Zig support requires separate typed-adapter evidence.

## Compatibility evidence

None verified.

## Versioning

Templates and family schemas follow independent SemVer.
