# Contenu généré

Cette famille contient des sorties JSON générées et versionnées individuellement. Leur présence dans le registre certifie uniquement leur intégrité par SHA-256.

Les champs déclarant un équilibrage, une validation ou une préparation à l'import proviennent des fichiers sources. Ils ne prouvent ni qualité narrative, ni équilibrage runtime, ni compatibilité client ou serveur.
