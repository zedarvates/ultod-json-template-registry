# Chauve-souris géante originale v0.1.0

Génome expérimental de revue, six pièces originales et fragment de configuration à intégrer dans une copie de l’éditeur. Les éléments proviennent de la géométrie procédurale locale de la chauve-souris originale ; aucune image ou géométrie historique n’est incluse. Les couleurs unies sont nouvelles.

Import, export et rechargement vérifiés dans l’éditeur en configuration isolée ; import statique dans Godot. Les deux pattes et ailes sont des pièces statiques sans rig. Aucun mouvement, vol, gameplay, collision complète, serveur, VR ou approbation artistique n’est certifié.
