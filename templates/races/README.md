# Races templates

## Purpose

Minimal declarative races classifications.

## Required fields

`display_name`.

## Optional fields

Only fields defined by the exact family schema.

## Authoritative exclusions

Excluded: stats, timings, costs, probabilities, loot contents, AI weights, lore, dialogue, and asset paths.

## Intended consumers

LLM pipeline and the future disabled-by-default Zig adapter.

## Compatibility evidence

None verified.

## Versioning

Each template and family schema follows independent SemVer.
