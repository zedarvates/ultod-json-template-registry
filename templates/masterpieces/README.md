# Masterpieces templates

## Purpose

Minimal declarative masterpieces identity and classification.

## Required fields

`display_name`; masterpieces may include `profession_tag`.

## Authoritative exclusions

Excluded: stats, difficulty values, experience, materials, result items, skill caps, skill lists, narrative beats, outcomes, points, tiers, rewards, buffs, and runtime rules.

## Intended consumers

LLM pipeline only. Zig support requires separate typed-adapter evidence.

## Compatibility evidence

None verified.

## Versioning

Templates and family schemas follow independent SemVer.
